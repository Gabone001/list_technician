# Python CLI Management Systems

This repository contains two command-line (CLI) applications built in Python for managing real-world data using file-based storage.

---

## 📌 Projects Included

### 🔹 IT Technician Management System
A system for managing IT technicians, including their roles and years of experience.

Features:
- Add, edit, and delete technicians
- View all technicians
- Filter by job role
- Generate summary report

---

### 🔹 Vehicle Service Management System
A system for tracking vehicle service intervals and maintenance status.

Features:
- Add, update, and delete service records
- Display all vehicles with service status
- Generate service alerts for overdue vehicles
- Store deleted records
- Save updates to file

---

## 🛠 Technologies Used

- Python
- File handling (read/write operations)
- Lists and basic data structures
- Menu-driven CLI systems

---

## 📂 Files

- `list_technician_extra_ex.py` – IT technician system
- `service_book.py` – vehicle service system
- `staff.txt` – technician data
- `services.txt` – vehicle data
- `report.txt` – generated report
- `deleted.txt` – deleted service records log
